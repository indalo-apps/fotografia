# FotoLab · Aprende fotografía

© 2026 **Adela Moreno Vega** y **Carlos Moreno Otto**. Todos los derechos reservados (ver [LICENSE](LICENSE)).

App para aprender fotografía (15-16 años): una cámara simulada para entender la apertura, la velocidad de obturación, el ISO y la profundidad de campo; retos de exposición con estrellas; ejercicios de composición (regla de los tercios, horizonte, regla del aire); teoría breve y un test. Se puede instalar en el móvil y funciona sin conexión.

Se publica con GitHub Pages: https://indalo-apps.github.io/fotografia/

Para sacar una versión nueva: subir el número en `<meta name="app-version">` (index.html) y en `CACHE` (sw.js). Los móviles que la tengan abierta se actualizan solos, sin cortar nada a medias.
